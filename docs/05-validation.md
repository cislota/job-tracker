## Автоматические проверки
Среда: Windows, Node.js v22.20.0.
- `npm.cmd run check` — синтаксис сервера и клиентского модуля.
- `npm.cmd test` — 8 интеграционных тестов: регистрация/вход/выход, полный жизненный цикл вакансии, изоляция двух пользователей, валидация, экспорт, изолированное демо, Origin/Host и защитные заголовки, сохранение после перезапуска.

При первой проверке обнаружено неверное число плейсхолдеров INSERT задач. Исправлено; дополнительно усилен тест изоляции, чтобы он сначала подтверждал успешное создание проверяемой задачи. Повторная проверка прошла.

## Браузерные проверки
Проверено в браузере на http://127.0.0.1:4318:
- Демо создаёт отдельное пространство с 8 вымышленными вакансиями.
- Создание тестовой вакансии «Тестовая студия / AI-разработчик».
- Переход Сохранена → Интервью отражается в истории.
- Добавление интервью на текущий день в 17:30 и заметки.
- После перезагрузки страницы вакансия, этап, задача и заметка сохранились.
- Выполнение задачи убирает её из списка активных действий «Сегодня».
- Поиск «Тестовая» возвращает одну вакансию; очистка клавиатурой возвращает список.
- Доска и обзор открываются.
- Осмотр широкого экрана 1440×1000 и мобильных экранов 390×844, 330×844.
- Исправлено переполнение страницы из-за абсолютно позиционированных скрытых подписей в доске: введён локальный containing block. После исправления scrollWidth страницы равен clientWidth; прокрутка остаётся только внутри доски.
- На узком экране доступны все разделы и выход; форма не выходит за ширину страницы.

## Не проверено / пределы результата
Нет live-вызова AI, публичного HTTPS-размещения, Docker-сборки, проверки под реальной нагрузкой, проверки на физическом телефоне или полноценного accessibility-аудита. Экспорт проверен через HTTP-тесты; скачивание файлов через браузер вручную не проверялось. Восстановление из пользовательской резервной копии не выполнялось. Это первая локальная версия для пилота, а не подтверждённый публичный production-релиз.
