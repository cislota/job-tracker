# Экраны и данные

Визуальный стиль: тёплый светлый фон, тёмно-синий текст, изумрудный акцент, спокойная типографика, компактные статусы. Главный акцент — следующее действие. Название: «Следующий шаг».

## Навигация
Постоянное боковое меню на широком экране / верхнее меню на мобильном: Сегодня, Вакансии, Обзор. Карточка вакансии — отдельный маршрут, возврат ведёт к списку. Кнопка добавления доступна в шапке каждого основного экрана.

Сегодня: приветствие → четыре счётчика → просроченные и сегодняшние задачи → ближайшие действия → недавние вакансии.
Вакансии: поиск + фильтры → список / доска из шести колонок → карточка. На мобильном доска горизонтально прокручивается, список доступен без горизонтального скролла.
Карточка: компания/должность/этап → зарплата/формат/ссылка → действия и задачи → описание → заметки/история.
Обзор: суммарные показатели → распределение текущих этапов → воронка по истории → пояснение методики → экспорт.

Все формы имеют видимые подписи; диалоги поддерживают Escape, ограничение фокуса и возврат фокуса; сообщения об ошибках объявляются screen reader. Кнопки изменения этапа заменяют drag-and-drop, чтобы работать с клавиатуры и телефона.

## Схема
users(id, email UNIQUE, password_hash, salt, is_demo, created_at)
sessions(token_hash PK, user_id FK, expires_at)
jobs(id, user_id FK, company, title, url, description, requirements, location, work_format, salary_min, salary_max, currency, salary_period, salary_tax, status, created_at, updated_at)
events(id, job_id FK, user_id FK, kind, body, from_status, to_status, created_at)
tasks(id, job_id FK, user_id FK, title, kind, due_date, due_time, completed, created_at)

user 1:N jobs; job 1:N events/tasks; user 1:N sessions. Удаление каскадное. Запросы содержат user_id из серверной сессии. Изменение этапа и запись события выполняются в одной SQLite-транзакции.

## Техническое решение
Node.js 22.13+ со встроенным node:sqlite, node:http и node:crypto. Интерфейс — ES modules и CSS без сборщика и внешних CDN. Решение выбрано из-за доступного локального окружения без установки npm-зависимостей. Это осознанное отклонение от предложенного Next.js/Supabase: REST API и UI разделены, перенос интерфейса на React возможен позже. Для нескольких серверных экземпляров потребуется замена SQLite на общую БД.
