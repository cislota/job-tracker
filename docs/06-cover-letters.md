# Профиль и сопроводительные письма

## Как пользоваться

1. Откройте «Мой профиль». Заполните опыт, контакты и навыки через запятую.
2. Добавьте версии резюме для разных ролей. Достаточно краткого опыта или текста резюме; загрузка PDF/DOCX пока не поддерживается.
3. Добавьте проекты: технологии, функциональность, личный вклад, результаты и ссылку. Указывайте помощь AI-инструментов там, где она использовалась. Примеры из задания автоматически не добавляются.
4. В карточке вакансии заполните описание и требования. В блоке «Сопроводительное письмо» выберите резюме, проекты, стиль и объём, затем нажмите «Составить письмо».
5. Проверьте и отредактируйте текст. «Сохранить версию» добавляет новую запись; старые версии можно открыть и скопировать.

Черновики сохраняются в памяти текущей вкладки при переходах между экранами. Для сохранения после перезагрузки нажмите «Сохранить версию». При перезагрузке с несохранённым письмом браузер предлагает подтверждение. Повторная генерация и открытие старой версии также запрашивают подтверждение замены несохранённого текста.

## Алгоритм и границы

Версия 1 работает без ключей и внешних запросов. `letter-generator.mjs` ищет совпадения собственных навыков с текстом вакансии с учётом нескольких вариантов написания технологий. Выбранные проекты ранжируются по этим совпадениям. Используются до двух проектов для короткого письма и до трёх для подробного. Краткий опыт выбранного резюме имеет приоритет над общим профилем. Указание помощи AI в личном вкладе сохраняется.

Пожелания служат ключевыми словами для приоритета фактов, а не произвольными инструкциями. Нет семантического анализа, проверки истинности введённого опыта, автоматической отправки работодателю или импорта вакансии по URL. Длина короткого письма приблизительная: многословный личный вклад и AI-атрибуция могут увеличить число предложений. При отсутствии совпадений показывается предупреждение; требования работодателя не превращаются в достижения кандидата.

## Данные и API

`career.mjs` добавляет таблицы `profiles`, `resumes`, `portfolio_projects`, `cover_letters` в существующую SQLite-базу без удаления старых таблиц. Все материалы принадлежат пользователю. Версии письма принадлежат вакансии; удаление вакансии удаляет её письма. Удаление резюме или проекта не удаляет уже сохранённый текст и снимок данных.

- `GET/PUT /api/profile`
- `GET/POST /api/resumes`, `PUT/DELETE /api/resumes/:id`
- `GET/POST /api/projects`, `PUT/DELETE /api/projects/:id`
- `GET /api/jobs/:id/letters`
- `POST /api/jobs/:id/letters/generate` — возвращает черновик, факты и предупреждения, не сохраняет версию.
- `POST /api/jobs/:id/letters` — сохраняет текст и настройки как новую неизменяемую версию.

Настройки: `resume_id`, `project_ids`, `style` (`natural`/`formal`), `length` (`short`/`detailed`), `wishes`. При сохранении создаётся снимок выбранных материалов и вакансии на момент сохранения. Он не доказывает происхождение произвольных ручных правок. JSON-экспорт версии схемы 2 включает профиль, резюме, проекты, письма, настройки и снимки. CSV по-прежнему содержит только вакансии.
